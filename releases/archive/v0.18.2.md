机器人回复带换行时，日志会变成这样：一条记录被拆成三行，而且回复记了两遍。

```
执行完成 · 收到回复「您已经签到过了！
当前有 342 点积分」
· 收到机器人回复 #18948：您已经签到过了！
当前有 342 点积分
▶ 回复：您已经签到过了！
当前有 342 点积分
```

## 修复

- **回复折成一行**：新增 `oneLine()`，换行折成 ` / `、连续空白收成一个、超长截断。
  回复在写入结果前就压平，日志行与任务「最近结果」都用压平后的文本
- **不再重复记**：`▶ 回复：…` 与 `· 收到机器人回复 #id：…` 是同一件事，删掉前者

现在长这样：

```
执行完成 · 收到回复「您已经签到过了！ / 当前有 342 点积分」
▶ example_bot
· 目标类型：机器人
· 步骤1 发送「/sign」
· 收到机器人回复 #18948：您已经签到过了！ / 当前有 342 点积分
```

## 测试

- 执行器以前没有测试（需要 Telegram client）。这次用假 client 跑真实执行路径，新增 3 例：
  - 多行回复：折成一行，且日志里只出现一次
  - 群组场景：拿到的是别人发的回复
  - 自己发的消息：不会被当成回复（`replyText` 为空）
- 单测 155 → **158**，端到端 48 项，均通过
