## 版本检查

- 最新版本读取 GitHub `main` 的 `package.json`，未打 tag 的版本也能提示；有对应 Release 时使用其链接，否则指向 `CHANGELOG.md`。
- 检查结果缓存绑定构建 ID，重新构建/部署后自动失效；「重新检查」「重试」强制刷新。
- 关于页显示执行节点构建，与页面构建不一致时提示重新部署。

## 日志

- 按钮列表按真实行分组，同一行的列用 ` | ` 分隔，保留 `[行,列]`；超过 20 个按钮时截断并显示总数。
- 点击日志只显示按钮文本。
