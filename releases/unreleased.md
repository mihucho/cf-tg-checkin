## 隐私

仓库和已发布页面里不再出现真实的签到对象（机器人用户名、数字 id、显示名共 5 处），
全部换成占位符：

| 之前 | 现在 |
| --- | --- |
| 真实机器人用户名 | `example_bot` |
| 真实数字 id | `123456789` |
| 真实显示名 | `示例机器人` |

这些原本散落在发布说明、CHANGELOG、测试用例和代码注释里，等于把真实的签到对象公开了。
现在：

- 当前仓库文件、四个已发布版本的 Release 说明、四个 tag 的注释都已清理（提交对象未变，Release 未受影响）
- 新增 `npm run lint:copy` 的**隐私黑名单**：扫全仓文本文件（md/ts/js/mjs/json），
  命中真实标识直接失败，CI 会拦
- `AGENTS.md` 加「隐私」一节：示例、日志、截图、tag 注释一律用占位符

## 发布流水线

- 支持 `retro: true`：在发布文档里写上一个**已发布**的版本号并加 `retro: true`，
  工作流只会用 `gh release edit` 更新它的 Release 说明（脱敏、纠错），不动代码、不重新打 tag
- 重置发布文档时如果原文没有使用说明，会用内置模板回填（之前 retro 模式重置过一次，把说明弄丢了）

## 升级注意

- 纯文档与工具链改动，无代码行为变化、无数据变更
