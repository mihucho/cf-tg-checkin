## 任务与界面

- **任务搜索**：页头搜索框按任务名、目标、分组、动作或编号过滤，与分组筛选叠加生效；搜不到时给出提示与「清空搜索」。
- **复制任务**：任务卡片可直接复制，副本名称加「副本」、默认停用，并沿用分组与全部配置。
- **批量操作**：全选本页、设置分组、批量启用/停用、批量删除；删除确认里列出任务名，并说明日志一并清理。
- **卡片式任务列表**：状态、目标、调度、下次执行、最近结果与步骤日志集中在一张卡片；窄屏按卡片信息层级展示。
- 任务卡片可展开「本次步骤日志」；图标按钮悬停/聚焦即时显示提示，触屏自动关闭。
- 设置 → 关于新增版本检查：读取 GitHub 最新 Release，缓存 6 小时；可用 `GITHUB_REPO` 覆盖仓库。

## 执行与调度

- 多步骤任务在最后一步之后抓取对方回复：点击收尾的任务同样能看到机器人返回的文字或新菜单。
- 执行结果按步骤成败判定；多目标全部成功才算任务成功。
- 手动执行与定时执行分开记录（`lastRunSource`）；手动执行不影响当天的定时。
- 时间预算覆盖单步等待与点击；`run-all` 按时间分批，网关 524/504 时提示任务可能仍在后台执行。
- 存储告警与成功率告警按每天一次节流，其余通知 1 小时。
- 超时 5–90 秒、删除延迟 0–3600 秒、间隔 1–10080 分钟；非法数字取默认值；空目标在入口拒绝。

## 编辑器

- 新建任务继承当前分组，选「未分组」可清空；目标留空使用设置里的默认目标。
- 带话题的目标保持已解析；清空「其他目标」删除附加目标；只改话题时保留 `accessHash`。
- 「等价指令」可复制，并可存为模板。
- 任务/日志搜索防抖重绘后保持焦点与光标；日志页轮询不打断输入。
- 页头时钟、下次执行、任务详情与日志时间统一按 `Settings.timezone` 显示。
- 日志请求按序号应用，读取失败显示错误状态。

## 安全与隐私

- `/api/state` 与 `/api/settings` 统一脱敏：手机号、账号 id、`api_id`、`accessHash`、Webhook 地址、管理员 id；Turnstile Secret 与 Webhook 加签密钥只返回 `*Configured`。
- 设置页 Webhook 输入框留空表示保持现有地址；固定渠道 Token 留空不修改。
- 登录按钮状态跟随人机验证开关；一次性 Turnstile token 在登录、退出、401 时清空。
- 请求体按字节限长；`/api/logout` 校验 Origin；代理层返回统一错误文案；删除任务清理通知节流键；延迟删除失败写入日志。
- 示例、测试、截图与发布说明统一使用占位符。

## 维护

- 发布文档支持 `tag: false`：版本号、CHANGELOG、归档与部署照常，跳过 tag 与 GitHub Release。
- 发布工作流：模板状态只汇总并结束；release job 仅限 `main`；retro/revoke 提交文档复位；push 冲突重试；按 `RELEASE_TOKEN` 选择级联或显式部署。
- tag 注释使用 `--cleanup=verbatim` 保留 Markdown 标题。
- `runtime` 暴露构建信息与存储用量；关闭 Workers Logs 采集，排障使用应用内「日志」页。
- 单测 185 例，集成测试 72 项；`docs/API.md` 覆盖新增字段、`run-all` 分批参数与内部端点。
