## 文案统一

| 类别 | 之前 | 现在 |
| --- | --- | --- |
| 动词 | 运行全部 / 检查调度 / 跑一次看看 | 执行全部 / 立即检查 / 执行一次试试 |
| 名词 | 签到任务 | 任务 |
| 缩写 | 未登录 TG、DO 区域 | 未登录 Telegram、部署区域 |
| 内部取值 | 默认 self（收藏夹）、`controlChat` | 默认读收藏夹、设置里的「指令来源」 |

| 开发者词 | `timestamp + sign`、`POST 一份 JSON（含 taskId / taskName…）`、`0 基`、`bot` | 「会自动算加签」「含任务编号、任务名、结果、时间」「从 0 开始」「机器人」 |
| 标点 | `(无消息)`、`签到成功, 已签到` | （无消息）、签到成功，已签到 |

## Telegram 里的消息也一起改了

帮助文本重写成分段结构，示例都是能直接复制的指令：

```
写法：[时间] + [要做的事]

时间（放在哪都行）
 · 9.30 / 09:30 / 0930 / 9点半
 · 窗口：8.30-10.30（这段时间里随机挑一次）
 · 间隔：每30分 / 每2小时
```

回复格式统一：

```
✅ 已创建任务 #12「每日签到」
⏰ 下次执行 10/25 09:30（UTC+8）

🗑️ 已删除任务 #12「每日签到」
⏸️ 任务 #12「每日签到」已停用
```

- 任务列表每行带上目标类型（机器人 / 群组 / 频道 / 用户）
- 解析报错改成「缺什么 + 怎么补」：`缺时间：在最前面写上几点执行，例如「9.30 签到」`
- 试算预览不再出现空目标：`每天 09:30 → 目标待选：发送「签到」`（任务名也不会变成「（待指定目标） 签到」）
